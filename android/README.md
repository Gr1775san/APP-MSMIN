# App Android de Estructural MSMIN

Abre https://gr1775san.github.io/APP-MSMIN/ como app (Trusted Web Activity con el Chrome del teléfono).
GitHub Actions la compila con cada cambio en esta carpeta y la publica en:
https://github.com/Gr1775san/APP-MSMIN/releases/latest/download/msmin.apk

- Firma: `msmin.jks` (PKCS12, alias `msmin`), protegida por el secreto `ANDROID_KEYSTORE_PASS`.
- Versión: número de ejecución del workflow.
